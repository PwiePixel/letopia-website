Letopia läuft für **Java** und **Bedrock**. Beide Versionen landen in derselben Welt, du kannst also mit Freunden spielen, egal auf welcher Plattform sie sind.

## Java Edition

1. Minecraft starten und auf **Mehrspieler** klicken.
2. **Server hinzufügen** wählen und als Adresse `letopia.net` eintragen.
3. Mit **Fertig** speichern und doppelt auf den Server klicken.

Empfohlen ist Version **1.21** oder neuer. Ältere Versionen können funktionieren, einige Custom Items sehen dort aber falsch aus.

## Bedrock Edition

| Feld | Eintrag |
| --- | --- |
| Servername | Letopia |
| Serveradresse | `letopia.net` |
| Port | `19132` |

Auf dem Handy und am PC geht das direkt über den Reiter **Server**. Auf Konsolen (Switch, PlayStation, Xbox) lassen sich eigene Server nur über Umwege hinzufügen, zum Beispiel mit der App *BedrockTogether*.

> [!INFO]
> Bedrock-Spieler bekommen auf dem Server einen Punkt vor den Namen, zum Beispiel **.Steve**. So lassen sich Java- und Bedrock-Namen nicht verwechseln.

## Probleme beim Verbinden

**„Verbindung abgelehnt“ oder Zeitüberschreitung:** Prüfe zuerst, ob du die Adresse richtig geschrieben hast. Schau dann im Discord unter *#status*, ob gerade Wartungsarbeiten laufen.

**„Veralteter Client“:** Deine Minecraft-Version ist zu alt. Aktualisiere den Launcher oder wähle im Profil eine neuere Version.

**Resourcepack lädt nicht:** Das Serverpaket brauchst du für Custom Items. Wenn die Abfrage nicht erscheint, stelle in der Serverliste unter *Bearbeiten* die Option **Serverressourcenpakete** auf *Aktiviert*.

Klappt es immer noch nicht? Dann öffne ein Ticket, siehe [[support]].
