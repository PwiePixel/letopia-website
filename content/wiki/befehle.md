---
titel: Wichtige Befehle
beschreibung: Die Befehle, die du im Alltag wirklich brauchst – zum Kopieren anklicken.
aktualisiert: 2026-09-18
---

Klick auf einen Befehl, um ihn in die Zwischenablage zu kopieren. Eine vollständige Liste bekommst du im Spiel mit `/hilfe`.

## Allgemein

| Befehl | Was er macht |
| --- | --- |
| `/spawn` | Teleportiert dich zum Spawn |
| `/warp` | Öffnet die Liste aller Warps |
| `/tpa Name` | Fragt, ob du dich zu einem Spieler teleportieren darfst |
| `/tpaccept` | Nimmt eine Teleport-Anfrage an |
| `/msg Name Text` | Schickt eine private Nachricht |
| `/ignore Name` | Blendet Nachrichten eines Spielers aus |

## Grundstück

| Befehl | Was er macht |
| --- | --- |
| `/p auto` | Gibt dir ein freies Grundstück |
| `/p home` | Bringt dich zu deinem Grundstück |
| `/p add Name` | Spieler darf bauen, solange du online bist |
| `/p trust Name` | Spieler darf immer bauen |
| `/p deny Name` | Sperrt einen Spieler von deinem Grundstück aus |
| `/p info` | Zeigt Infos zum Grundstück, auf dem du stehst |

Mehr dazu unter [[grundstuecke]].

## Geld & Handel

| Befehl | Was er macht |
| --- | --- |
| `/money` | Zeigt deinen Kontostand |
| `/pay Name Betrag` | Überweist Coins an einen Spieler |
| `/ah` | Öffnet das Auktionshaus |
| `/ah sell Preis` | Stellt das Item in deiner Hand ein |
| `/jobs` | Öffnet das Job-Menü |

## Stadt

| Befehl | Was er macht |
| --- | --- |
| `/stadt` | Öffnet das Stadtmenü |
| `/stadt gruenden Name` | Gründet eine neue Stadt |
| `/stadt beitreten Name` | Nimmt eine Einladung an |
| `/stadt kasse` | Zeigt die Stadtkasse |

> [!TIPP]
> Viele Befehle haben auch ein Menü. Wenn du dir unsicher bist, gib nur den Hauptbefehl ein, zum Beispiel `/stadt`, und klick dich durch.
